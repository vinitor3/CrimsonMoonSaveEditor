# Crimson Moon Save Editor — public code edition

Edit currencies, equipment, rarity, persistent blessings and supported campaign fields through a portable desktop interface. Includes equipment comparison, five skull difficulty selection, backups, undo/redo and eight interface languages.

Created by **vinitor3** with **GPT (OpenAI) assistance**. AI was used for code, interface, translations and tests. Research tools: [FModel](https://github.com/4sval/FModel) and [UE4SS](https://github.com/UE4SS-RE/RE-UE4SS). Neither is bundled or required at runtime.

Source code, license and build instructions: [GitHub](https://github.com/vinitor3/CrimsonMoonSaveEditor).

This public edition uses original generic icons and technical aliases. Extracted game artwork and official item/effect descriptions are not distributed. It is unofficial and not endorsed by the game studio.

Close the game before applying changes and keep independent backups. Some equipment, blessing and campaign edits remain experimental; structural validation is not a guarantee of compatibility with every game build. Profile metadata, control mappings and game-created backup files are not edited.

If uploading a compiled Windows release, upload the **public edition** portable ZIP together with its matching **library-sources ZIP**, license files and checksums. Do not upload a locally customized package containing unlicensed game assets.
