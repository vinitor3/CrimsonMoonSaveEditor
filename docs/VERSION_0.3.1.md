# Version 0.3.1 — original legacy package

This release provides the original portable 0.3.1 ZIP with in-game equipment/blessing icons, decorative artwork and official localized names/descriptions. It has not been replaced with a generic-resource rebuild. The 0.3.2 public edition remains the current version and uses generic icons and technical aliases.

Features include currencies, equipment and rarity, comparisons, persistent blessings, five-skull difficulty selection, supported manual campaign positions, character rename, supported consumable quantities, eight interface languages, undo/redo, review and backups. Some edits remain experimental; preserve independent backups and close the game before applying changes.

## Downloads and identity
